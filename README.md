## 🏦 Banking App UI (Figma Design Implementation)

This project focuses on building a **modern banking mobile application UI** by closely following a **Figma design** and implementing real-world features using Flutter.

---

### 🎨 Design Approach
- Pixel-perfect UI implementation from Figma
- Clean and modern banking interface
- Focus on UI/UX best practices
- Responsive layout for different screen sizes

---

### 🔐 Authentication Screens
- Sign Up Screen
- Sign In Screen
- Forgot Password
- Change Password

Features:
- Form validation
- Error handling
- Smooth navigation between screens

---

### 🏠 Home Screen
- Dashboard layout
- Quick action buttons
- Animation card swippers 
- Clean grid-based design

---

### 🧩 Concepts Applied

#### 🔹 UI & Widgets
- Custom reusable widgets
- Responsive layout using Row, Column, Expanded
- Proper spacing & alignment

#### 🔹 State Management
- Cubit / Bloc for managing UI state
- Handling loading, success, and error states

#### 🔹 Clean Architecture
- Separation of Presentation, Domain, and Data layers
- Scalable and maintainable code structure

#### 🔹 Dependency Injection
- Using GetIt for managing dependencies

---

### ✨ Additional Features
- Animations for smooth user experience
